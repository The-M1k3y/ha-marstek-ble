# Control messages

* [`0x05` EPS mode](05-eps-mode.md) - Boolean EPS-mode control.
* [`0x06` AC input](06-ac-input.md) - Boolean AC-input control.
* [`0x07` Generator](07-generator.md) - Boolean generator control.
* [`0x09` Buzzer and manual mode](09-buzzer-manual-mode.md) - Dual-use boolean command.
* [`0x0D` Charge mode](0d-charge-mode.md) - Charge-mode selector write.
* [`0x0E` Output and self-consumption](0e-output-self-consumption.md) - Dual-use output and operating-mode command.
* [`0x15` Power mode](15-power-mode.md) - Fixed power-mode value.
* [`0x16` AC power](16-ac-power.md) - AC power setpoint.
* [`0x17` Total power](17-total-power.md) - Total power setpoint.
* [`0x20` CT polling-rate write](20-ct-polling-rate-write.md) - CT polling-rate selector write.
* [`0x25` Reboot](25-reboot.md) - Empty-payload reboot request.
