# Telemetry and query messages

* [`0x03` Runtime information](03-runtime-information.md) - Runtime status, power, energy, temperature, and connectivity fields.
* [`0x04` Device information](04-device-information.md) - ASCII identity and firmware key/value response.
* [`0x08` Wi-Fi SSID](08-wifi-ssid.md) - ASCII SSID response.
* [`0x0D` System data](0d-system-data.md) - System status and five generic values.
* [`0x13` Timer information](13-timer-information.md) - Adaptive-mode and smart-meter status.
* [`0x14` BMS data](14-bms-data.md) - Battery limits, state, diagnostics, temperatures, and cell voltages.
* [`0x1A` Configuration data](1a-configuration-data.md) - Configuration mode, status, and value.
* [`0x1C` Logs](1c-logs.md) - Polled but currently unparsed log response.
* [`0x21` Meter IP](21-meter-ip.md) - Selector request and ASCII meter-address response.
* [`0x22` CT polling rate](22-ct-polling-rate.md) - Current CT polling-rate value.
* [`0x24` Network information](24-network-information.md) - ASCII IP configuration response.
* [`0x28` Local API status](28-local-api-status.md) - Accepted local-API enable state and port response.
